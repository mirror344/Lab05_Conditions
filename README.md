string GetHint(int difference)
{
    switch (difference)
    {
        case <= 3:
            return "🔥 Горячо!";

---

| Конструкция | Когда использовать |
| ----------- | ------------------ |
| if/else |  Общее ветвление, сложные условия |
| else if | Несколько взаимоисключающих вариантов |
| switch/case | Сравнение одной переменной с конкретными значениями|
| Тернарный оператор ? : | Выбор одного из двух значений в одну строку | 
| && | Оба условия должны быть истинны | 
| \|\| | Хотя бы одно условие должно быть истинно|
| ! | Отрицание условия |
| int.TryParse() | Безопасное преобразование строки в число |
| Random.Next(min, max) | Генерация случайного числа в диапазоне |

## Ответы на вопросы
1. `int.TryParse()` безопаснее, потому что `int.Parse()` аварийно завершает программу, если введенный текст не является числом. `int.TryParse()` лучше использовать если неизвестно точно будет ли введено число, `int.Parse()` лучше использовать если строка точно будет содержать число.
2. Оператор `switch` удобнее, когда нужно сравнить переменную с конкретными значениями. Например, оценка 5 - отличник, 4 - хорошист, 3 - удовлетворительно, 2 - плохо.
3. Если в `switch` убрать `break` после `case` «провалится» вследующий `case`
4. `=` приваивает значение переменной, а `==` сравнивает переменную со значением или другой переменной
5. Да, тернарный оператор можно написать внутри другого тернарного оператора. 
`string weather = temp >= 20 ? "тепло" : (temp > 0 ? "прохладно" : "мороз");`
Читаемость такого кода ухудшается, для больших условий лучше использовать `if/else`
